O que o AgroDados faz

Um sistema web em Django para registrar e consultar o que acontece no campo.

Propriedades

Cadastro das unidades produtivas, área, cultura principal e responsável.

Mapas e talhões

Desenhe os limites no mapa de satélite e calcule a área de cada talhão.

Produtos e insumos

Inventário com categoria, quantidade e ligação com as atividades.

Atividades agrícolas

Histórico de plantio, adubação, defensivos, irrigação e colheita.

Documentação

CAR, CCIR, ITR, escrituras e comodatos guardados com acesso restrito.

Relatórios

Indicadores calculados só com os registros reais da sua conta.

Privacidade

Cada usuário vê e altera somente o que cadastrou. A exclusão de qualquer registro exige a confirmação da senha. O administrador acessa o painel completo.

Colocar o sistema no ar

Esta página é apenas uma apresentação: o GitHub Pages não executa Python, banco de dados ou login. O sistema roda no Render.

  1. Crie um PostgreSQL gratuito no Neon e copie a DATABASE_URL.
  2. Crie um bucket privado no Cloudflare R2 para os documentos e fotos.
  3. No Render, crie um Blueprint a partir deste repositório e preencha as variáveis secretas.
  4. Depois do deploy, crie o primeiro usuário com python manage.py createsuperuser.

Passo a passo completo no README do projeto.
